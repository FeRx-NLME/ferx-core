- **The objective no longer depends on the units of DV** (#2441): a residual variance
  below `1e-12` used to be raised to `1e-12`, so a proportional-error observation
  predicted below about `1e-6/σ` (or an additive one with `σ ≤ 1e-6`) was scored
  with the wrong variance, and the same model and data in ng/mL and mg/L gave
  objectives that differed by more than `2·n·ln k`. Every positive variance is now
  scored as computed, as in NONMEM; only a zero, underflowed or `NaN` variance is
  still replaced by `1e-12`. Fits with such observations change their OFV.
