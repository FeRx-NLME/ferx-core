- Closed-form (analytic) models with a long dose history fit much faster. Each interval of the
  event walk, and of the gradient walk beside it, used to rescan every dose record, so a walk's
  cost grew with the square of the doses per subject; the walks now read a time-sorted index of
  the doses instead. One evaluation of a two-compartment oral model with an estimated lag and
  IOV takes 1.9 s instead of 14.1 s at 200 doses per subject, and 3.8 s instead of 50.1 s at 400.
  Predictions and objective values are unchanged bit for bit. The outer gradient changes only
  by rounding, so a fit can take a slightly different path to the same optimum (#2754).
