- **A larger `inner_screen` no longer misses a mode a smaller one finds** (#2863): the
  screen descended from its three lowest Sobol points, and a larger screen puts more points
  around the mode a subject already has, so all three descents could land back in it. The
  three starts are now the lowest points more than 0.5 apart in the Ω⁻¹ metric (from the 32
  lowest), with the same number of descents. On `data/two_cpt_oral_cov.csv` with the
  issue's model, `inner_restarts = 20, inner_screen = 2000` now reaches the lower mode
  (OFV −913.6679) that `inner_restarts = 8, inner_screen = 400` finds, instead of stopping
  at −901.3676. Every bundled example gives the same OFV as before.
