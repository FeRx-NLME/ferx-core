- **A branch-only helper named like a block keyword is no longer refused**
  (#1902): the #1857 check counted the key on the left of `=` in another block
  as a read, so a helper named `RATE` or `SHAPE` was refused as "named in
  `[event_model]`" although nothing outside its branch read it. Keys and
  targets left of `=` (`rate`, `d/dt(central)`, `init(central)`,
  `transition A -> B`) and the word values of the endpoint blocks
  (`family = weibull`, `type`, `clock`, `link`, the `states` labels) no longer
  count as reads.
