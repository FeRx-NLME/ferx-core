- **A fit's own estimate on a declared bound is a valid start again** (#2896): a log-packed
  `theta` that ends on its bound is reported one ULP outside it (`exp(ln(10))` is
  10.000000000000002), so starting a new fit from those estimates was refused with
  `E_THETA_INIT_OUTSIDE_BOUNDS`, and an evaluation-only run warned with
  `W_THETA_INIT_OUTSIDE_BOUNDS`. A value within its bound's round trip now counts as inside.
