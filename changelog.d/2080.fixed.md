- The inner (EBE) BFGS no longer gives up on a start point far from the mode (#2080). An
  `inner_restarts` seed whose objective is around 1e10 has a gradient so large that its first
  step overshot every one of the 30 line-search trials, so the solve fell back to
  Nelder–Mead from η = 0 and the seed never got its own descent. A failed line search now
  retries once with the step scaled by 1/‖g‖. On a one-compartment flip-flop subject this
  lets the seed reach the deeper mode (−44.02 instead of the twin at −21.07). A solve whose
  line search succeeds takes the same path as before.
