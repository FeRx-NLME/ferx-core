- The inner (EBE) BFGS no longer gives up on a start point far from the mode (#2080). A start
  whose objective is around 1e10 has a gradient so large that its first step overshot every one
  of the 30 line-search trials, so the solve failed at once. From an EBE solve's own start that
  sent it to the Nelder–Mead fallback from η = 0; in the `inner_restarts` multi-start, which has
  no fallback, the seed was dropped and the trapped mode kept. A failed line search now retries
  once with the step scaled by 1/‖g‖. On a one-compartment flip-flop subject this lets the seed
  reach the deeper mode (−44.02 instead of the twin at −21.07). A solve whose line search
  succeeds takes the same path as before. The retry also reaches the BFGS polish that certifies
  a Nelder–Mead endpoint, so a polish that failed before may now certify it.
