- **A fit warm-started at a converged optimum now reports converged** (#2506): a
  bootstrap sample or refit started at a previous fit's estimates does not move, and
  was reported `converged = false` with `W_STALLED_AT_INIT`. When the NLopt outer loop
  does not leave its start it now tests whether the start is first-order optimal (BHHH
  Newton decrement ≤ 0.1); a stationary start is reported converged, is not flagged,
  passes `Strictness::default()`, and is recorded in the new
  `FitResult::stationary_start`. A cold start that stalls is still flagged, and the
  warning no longer claims the objective is meaningless for a start it could not test.
