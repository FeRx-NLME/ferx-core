- **A fit warm-started at a converged optimum now reports converged** (#2506): a
  bootstrap sample or refit started at a previous fit's estimates does not move, and
  was reported `converged = false` with `W_STALLED_AT_INIT`. When the NLopt outer loop
  does not leave its start it now tests whether the start is first-order optimal (Newton
  decrement ≤ 0.1, analytic where the model has per-subject gradients and
  finite-differenced otherwise, AGQ and mixtures included). A stationary start is
  reported converged, is not flagged, passes `Strictness::default()`, and is recorded in
  the new `FitResult::stationary_start`. A start that is not stationary is now reported
  `converged = false` even when the optimizer claimed success, so bootstrap drops it, and
  the warning no longer claims the objective is meaningless for a start it could not test.
