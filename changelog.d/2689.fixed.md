- **`imp_eval_only` scores the same likelihood IMP/IMPMAP estimate** (#2689, #2627): with
  `imp_proposal_df = normal` the evaluation-only −2 log L is now finite, and on IOV models
  it includes FREM covariate rows, TTE / binary / categorical endpoints and
  `imp_defensive_alpha`, which it previously left out. The SAEM and method-chaining docs now
  show `imp_eval_only = true` for scoring a fit with `method = [saem, imp]`; without it the
  `imp` stage re-estimates the parameters.
