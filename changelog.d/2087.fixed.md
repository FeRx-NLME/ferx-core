- **A failed event-time solve no longer aborts a drug-driven TTE simulation** (#2087):
  when the ODE-accumulated hazard of one simulated subject cannot be solved (for
  example an `[odes]` state diverges for that subject's parameter draw), that subject
  is censored at the observation window (every cause, under competing risks) and named
  in a new `W_TTE_SOLVE_FAILED` warning, which says which `[odes]` state failed.
  The rest of the population still simulates, with the same rows as before.
  Previously the whole `simulate` call panicked; from R it was an error.
