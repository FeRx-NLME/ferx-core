- **Parsing a deep diamond of `[individual_parameters]` intermediates is no longer
  exponential** (#1699): the parser's symbolic ∂(individual parameter)/∂(θ, η)
  partials now read an upstream intermediate's partial by reference instead of
  copying it into every line that uses it, so a block where each level reads the
  previous one twice (`B = X + 1`, `C = X + 2`, `X' = B + C`) parses in time linear
  in its depth, where depth 30 used to run out of memory.
