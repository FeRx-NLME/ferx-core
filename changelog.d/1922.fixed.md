- **NCA start values no longer write the volume onto `TVCL`** (#1922): `inits_from_nca`
  routed a PK parameter with no η, or with an η not named after it (`ETA_VOL`), to the
  first θ whose name merely *contained* the parameter's name — `V` resolved to `TVCL`,
  which then held the volume estimate (often clamped at its bound) while `TVV` stayed
  at its default. The η is now found through the parameter it appears in, the name
  fallback matches whole words only and declines when ambiguous, and two roles that
  still resolve to one θ are both left at the model default with a warning.
