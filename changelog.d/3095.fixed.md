- **An endpoint row ahead of a subject's first PK record now starts its integration there**
  (#3095). This covers a TTE, count or discrete-state row before the first dose, as NONMEM
  starts the system at its first record of any kind. Before, the subject integrated from its
  first PK record, so a state that moves before the first dose, such as a non-equilibrium
  `init(...)`, read the wrong value. The rule no longer depends on file order. A subject
  with endpoint rows only still integrates from 0.
