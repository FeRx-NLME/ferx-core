- **An individual parameter read only by a named endpoint block is no longer reported
  "computed but never used"** (#1455). The census behind that warning read the unnamed blocks
  only. So a parameter used solely by a named `[event_model LABEL]` or `[binary_model LABEL]`
  predictor, such as `scale = LAM`, was reported dead, with advice to remove it that would have
  broken the hazard. The census now reads the named blocks too.
