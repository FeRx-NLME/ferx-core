- **An individual parameter read only by a named endpoint block is no longer reported
  "computed but never used"** (#1455). The census behind that warning read the unnamed blocks
  only. So a parameter used solely by a named endpoint block (`[event_model LABEL]`,
  `[binary_model LABEL]`, `[count_model LABEL]`, `[markov_model LABEL]`), such as `scale = LAM`,
  was reported dead, with advice to remove it that would have broken the predictor. The census now
  reads the named blocks too, except `[covariate_nn NAME]`, whose output names would hide a dead
  parameter.
