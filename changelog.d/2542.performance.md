- Fits on data with time-varying covariates are faster: `$PK` is now evaluated once per
  distinct set of record inputs (covariate values, occasion and, when the model reads `TIME`,
  the record time) and not once per record. Analytic FOCE/FOCEI fits on a 100-subject,
  two-covariate benchmark run about a third faster, and every result is bit-identical (#2542).
