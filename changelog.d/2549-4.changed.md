- **`predict_warm_etas` takes the first-order prediction whole** (#2549): the public
  Almquist Eq. 48 helper no longer caps a subject's predicted step at an L2 norm of 2. The
  mode response is the mode's exact derivative, so the uncapped start is second-order
  accurate; every cap measured lost outer iterations on some model. The fits that use it now
  re-solve from the previous mode any subject whose inner solve fails from its predicted
  start. The built-in `bfgs`/`lbfgs` outer loop now takes its mode response from the
  gradient's own sweeps, as the NLopt optimizers do, instead of a separate pass per accepted
  point, and like them leaves `[covariate_nn]` models unpredicted.
