- **A model file that does not parse is named in the error** (#1807): every entry that reads a
  model file through `ModelSource` (`fit_from_files()`, `prepare_run()`, `run_model*()`, the CLI
  `ferx model.ferx`, `prepare_frem()`, `run_sir()`, `run_covariance()`, the post-hoc resolver,
  and so ferx-r's `ferx_fit()`) reported a parse failure with the parser's message alone. They
  now say `error parsing the model file {path}: …`, as the read and hash failures already name
  the file. The error codes are unchanged.
