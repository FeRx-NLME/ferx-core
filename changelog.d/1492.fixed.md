- **`W_FILTER_COLUMN_ABSENT` now says what a condition on a missing column excludes**
  (#1492). It said "no rows are excluded" for every key. That holds for `ignore`, but an
  `accept` condition on a column the dataset lacks never passes, so it excludes every record.
  The warning now names the columns per key: an `ignore` condition on them excludes nothing,
  and an `accept` condition excludes every record.
