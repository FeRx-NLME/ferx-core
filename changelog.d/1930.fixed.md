- **`inits_from_nca` routes each NCA estimate reproducibly** (#1930): a pooled
  estimate now reaches the θ of the η its parameter actually reads, instead of the
  first η whose *name* ends in `_<PARAM>` — which, with two such names (`ETA_CL` on
  `CL`, `IIV_CL` on another parameter), was picked in hash order and could start the
  same fit from different values on different runs. A PK role bound to a literal
  (`cl=1.0`) or `TIME` is no longer given a guessed θ whose name merely contains the
  slot name; it is left as declared, and the warning now says so instead of
  blaming a missing η.
