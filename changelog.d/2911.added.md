- **`{model}-fit.json` now carries the estimates keyed by name, in the fit YAML's
  layout** (#2911): a top-level `estimates` object holds the YAML's `theta`,
  `omega`, `sigma`, `block_sigma`, `omega_iov` and `mixture_overrides` sections
  with the same entry and field names (`estimates.theta.TVCL.estimate` is the
  YAML's `theta.TVCL.estimate`), at full precision and with `null` for the YAML's
  `~`. A script reading final estimates no longer has to branch on which file it
  was given. Both are rendered from one table, so they cannot disagree.
