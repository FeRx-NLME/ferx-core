- **A `kappa` model with a residual `correlation` line now fits with L-BFGS under
  `optimizer = auto`** (#2122). Its gradient is finite differences (#2101), so `auto`
  picked BOBYQA, which stopped at a different objective for each starting value of the
  correlation, sometimes above the optimum of the same model without the line, and
  reported converged. An explicit `optimizer = bobyqa` is still honoured. The fit now
  also warns that this route uses finite differences and why; when such a model is also
  past the 24-axis cap of the analytic gradient, that warning no longer advises
  reducing the parameter count, which would not restore the analytic gradient.
