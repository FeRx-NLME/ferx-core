- **Mini-batch SAEM: `[fit_options] batch_fraction = α`** (#2607). Each SAEM
  iteration runs the E-step on a random `⌈α·N⌉` subjects only; the others keep
  their η, so every Ω/θ/σ statistic is still summed over all subjects (Kuhn,
  Matias & Rebafka 2020). Opt-in: the default `1` is bit-identical to full-batch
  SAEM. See the SAEM docs page for the measured cost/precision trade-off before
  using it.
