- **`optimizer = auto` runs L-BFGS on a `[mixture]` model** (#2739), like any other
  model in the analytic gradient's scope, instead of always BOBYQA. On the public mixture
  fixtures it reaches the best optimum about as often from random starts (within 3 of 100
  fits), in 5–8× fewer evaluations. A mixture started with indistinguishable classes (the same mixing probability
  and the same objective under every class) still runs BOBYQA, since a gradient optimizer
  cannot separate such classes; the fit warns `W_MIXTURE_SYMMETRIC_START` and reports
  `auto (bobyqa)`. The check is exact, so classes that start only close to each other run
  L-BFGS without a warning. Pin `optimizer = bobyqa` to keep the old behaviour.
