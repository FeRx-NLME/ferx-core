- **The data reader's warning for a covariate with no value for some subjects
  is now coded `W_COVARIATE_MISSING`** (#2041), so it can be filtered by its token
  and classifies as `data_quality` rather than `general`; `ferx check` relays it
  under that code instead of `W_DATA`. The message no longer carries two runs of
  14 spaces, and no longer says the covariate "evaluates to NaN": a relation that
  reads it through `log`, `sqrt`, `min`, `max` or a comparison gives a finite
  value, which the message now says.
