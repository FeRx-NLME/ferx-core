- **`simulate_with_uncertainty()` no longer asks for a horizon it cannot take** (#1774):
  a repeated-event or drug-driven TTE model, which needs a horizon, was refused with
  "set `SimulateOptions.horizon`", an option `SimulateUncertaintyOptions` does not have.
  It is now refused with `E_TTE_NOT_SIMULATABLE` and a message pointing to
  `simulate_with_options()`, which takes a horizon.
