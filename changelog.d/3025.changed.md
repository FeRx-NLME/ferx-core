- **Mixture models default to a gradient-based outer optimizer** (#3025):
  `optimizer = auto` on a `[mixture]` model now resolves to NLopt L-BFGS on the exact
  posterior-weighted mixture gradient for every method (FOCE, FOCEI, Laplace, AGQ), as for a
  single population; it used to resolve to BOBYQA. An explicit `bobyqa` is still honoured, and
  the built-in BFGS / L-BFGS / trust-region paths, which do not carry the mixture objective, now
  fall back to NLopt L-BFGS (with the existing warning) instead of BOBYQA.
