  evaluation** (#574): the per-subject EBE pass polls the cancel flag before each
  subject, so a cancel no longer waits out a full population pass — minutes on a large
  ODE model. The `trust_region` outer
  optimizer, which never polled the flag, now stops at its next iteration.
