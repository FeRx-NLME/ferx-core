- **`W_COVARIATE_MISSING` is raised only for a covariate the model reads** (#2599):
  a dataset column with missing values that no relation reads — an auto-detected
  lab value or ID the model never touches — no longer prints a warning claiming
  the objective goes `NaN`. A column named in `[covariates]` or the
  `covariate_columns` argument still warns; the model-blind `read_nonmem_csv*`
  readers, which cannot tell what a model reads, still warn for every column.
