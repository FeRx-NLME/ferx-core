- **On an analytical (`pk ...`) model, `[initial_conditions]` and a Form B
  `obs_scale` now read an individual parameter that no `pk(...)` role binds**
  (#1898). Such a parameter (`S = 1000`, then `init(central) = S`; or
  `SCF = WT / 70`, then `obs_scale = SCF`) had no PK slot of its own and silently
  read `CL`'s value instead: the init deposited `CL`, the scale divided by `CL`.
  It now takes a free differentiable slot, as a Form C `y = …` readout parameter
  already did, so predictions and analytic gradients use its own value. Validated
  against NONMEM 7.6.0 (`nonmem_anchor/unbound_reader_{init,scale}.ctl`). A model
  whose `y`, `obs_scale` and `[initial_conditions]` together reference more such
  parameters than the model has free slots is now a parse error naming them;
  inline the expressions instead.
