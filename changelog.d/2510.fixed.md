- **An observation listed before a same-`TIME` steady-state dose reads pre-dose**
  (#2510): like any other co-timed dose, an `SS=1` dose listed after an
  observation no longer reaches it. The observation reads the amounts carried
  from the previous record (0 before a first SS dose), as NONMEM does. Before,
  it read the post-dose steady state. A covariate-change row listed before an
  `SS=1` dose likewise governs the interval ending at it. Also, an ODE state read
  at a time less than `1e-12` before the subject's first record (a TTE or CTMM
  time, or a `[derived]` grid point) now reads the initial state instead of `NaN`.
