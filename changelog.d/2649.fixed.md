- **A parameter that sets an `[odes]` `if` switch is no longer silently frozen** (#2649):
  an `if` condition reading an estimated parameter and a state or clock, such as
  `if (tau > LAGT)`, switches at a time that moves with the parameter, which exact
  derivatives cannot see. A θ reaching the equations only that way got an analytic
  gradient of exactly zero and stayed at its initial value, sometimes with
  `converged: true`. These models now run on finite-difference gradients, with a
  warning naming the parameter. `min`, `max`, `clamp`, `FIX` parameters and
  covariate-only parameters stay analytic.
